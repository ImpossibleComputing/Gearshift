# Provenance

This public repository begins with the first Impossible Computing OSS release of
Gearshift. Earlier experimental Git history and original evidence are preserved
privately. The public tree omits third-party LiveCodeBench problem material and
retrieves pinned inputs from the official upstream source for reproduction.
This omission does not change the reported experimental results: retained numerical
records reproduce the published analyses. `gearshift-progress-02` identifies this
release snapshot; the earlier snapshot remains in the private historical archive.
